# 🔐 Security Policy

MathMind values the security of our users and contributors.  
This document outlines how to report vulnerabilities and how we handle API keys.

---

## 📌 Reporting Vulnerabilities
- If you discover a security issue, **do not open a public issue**.  
- Please contact the maintainers directly at [Asadullah](https://facebook.com/MdAsadullahAlMunib).  
- We will acknowledge your report as soon as possible and work on a fix promptly.  

---

## 🔑 API Key Security
MathMind requires users to provide their own API key for certain features.  
To keep keys secure:

- Keys are stored only on the user’s device.  
- They are never committed to the repository or shared publicly.  
- Keys are encrypted before storage.  
- Users can update or remove their API key at any time.  

👉 Please keep your personal API key private and never include it in issues or pull requests.
